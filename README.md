# Behavioral Analytics & Performance Decision Support System (B-DSS)

##  Overview
An executive Management Information System (MIS) designed to track, analyze, and visualize behavioral and performance metrics. The system bridges individual behavioral tracking with management dashboards, providing actionable decision support and early-warning alerts for organizational burn-out or low performance.

##  Repository Structure
- `docs/`: System architecture, DFDs, ERD diagrams, and project documentation.
- `database/`: Relational database schemas (SQL), mock datasets, and data dictionary.
- `dashboard/`: Interactive BI dashboard files (Power BI / Tableau) and summary reports.

##  System Architecture & Data Pipeline
1. **Data Collection & Entry**: Logging structured behavioral indicators and KPIs.
2. **Relational Database**: Storing users, behavioral metrics, and historic logs securely.
3. **Analytics & BI Engine**: Transforming raw logs into visual executive insights and proactive alerts.

##  Tech Stack
- **Database**: PostgreSQL / SQLite / MySQL
- **Analytics & BI**: Power BI / Tableau
- **Documentation**: Markdown, Draw.io / Mermaid.js
