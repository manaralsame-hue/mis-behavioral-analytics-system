# Executive Dashboard & Visual Analytics

## 📊 Overview
This folder contains the visual decision-support dashboard dataset and configurations for the B-DSS project.

## 🎯 Key Performance Indicators (KPIs)
- **Average Performance Metric**: Overall productivity index.
- **Burnout / Stress Alert**: Tracks high-stress indicators across departments.
- **Task Completion Trends**: Time-series evaluation of deliverables.

## 📁 Files
- `dataset.csv`: Processed relational dataset for BI tools (Power BI, Tableau, Python).
